# NOTHING IS DISALLOWED HERE, DELIBERATELY.
#
# /404 is kept out of the index by the meta noindex tag on the page itself plus the 404 status
# code it is served with. It is NOT listed below, because a path blocked in robots.txt is never
# crawled, so its noindex tag is never read, and Google can still surface a bare URL for it.
# One mechanism or the other, never both.
#
# The `Noindex:` robots.txt directive is not an option: Google stopped honouring it in
# September 2019 and it has been a no-op ever since.
#
# /press was Disallow-ed until 2026-09-17 and is now open. It carries the fast facts a
# journalist, a grant reviewer or an accelerator looks for, and keeping it out of search
# served nobody.

# ─── ANSWER ENGINES AND MODEL CRAWLERS ──────────────────────────────────────────────────────
#
# `User-agent: *` above already permits every one of these, and these blocks change nothing
# functionally. They are here for two reasons that are not about permission.
#
# FIRST, GOOGLE-EXTENDED IS NOT COVERED BY THE WILDCARD IN THE WAY IT LOOKS. It is a control
# token, not a crawler: Googlebot fetches the page under `*`, and Google-Extended decides
# separately whether Gemini and the grounding layer of AI Overviews may use what was fetched.
# A site that says nothing is treated as permitting it, but saying it outright removes the
# question — and this is the surface on which the company is currently being misidentified.
#
# SECOND, EXPLICIT IS PROTECTION AGAINST A FUTURE EDIT. The moment anyone adds a `Disallow:`
# under `*` — for a staging path, an asset directory, anything — every unnamed agent inherits
# it. A named group does not. These blocks are what makes that edit safe to make.
#
# This is a deliberate decision to be trained on and quoted. For a pre-revenue company whose
# name an answer engine currently reads as a typo, being in the corpus is the distribution.
